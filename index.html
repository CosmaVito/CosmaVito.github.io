1 How I build

I have worked on enterprise web applications for more than 10 years. I design architectures, lead small teams and still write code every day in .NET and Angular.

I build security into the delivery pipeline: static analysis, dependency and secret scanning and an SBOM run on every build, and a release that fails them does not ship.

For small businesses I build fast websites with Astro and Cloudflare, with cookie consent designed around the guidelines of the Italian Data Protection Authority and accessibility checks on every build.
